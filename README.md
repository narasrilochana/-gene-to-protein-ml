# DNA-to-Protein Translator & ML Classifier

## Project structure
- `app.py` — Streamlit application
- `.streamlit/config.toml` — Streamlit theme and server configuration
- `requirements.txt` — Python dependencies
- `assets/` — four supplied biology illustrations

## Run locally (Windows)
1. Install Python 3.10 or newer and enable **Add Python to PATH**.
2. Open Command Prompt in this folder.
3. Create a virtual environment: `py -m venv .venv`
4. Activate it: `.venv\\Scripts\\activate`
5. Install dependencies: `python -m pip install --upgrade pip` then `pip install -r requirements.txt`
6. Start the app: `streamlit run app.py`
7. Open the local URL printed by Streamlit, usually `http://localhost:8501`.

## Deploy to Streamlit Community Cloud
1. Create a GitHub repository and upload `app.py`, `requirements.txt`, `.streamlit/config.toml`, and the complete `assets` folder.
2. Visit https://share.streamlit.io/ and sign in with GitHub.
3. Select **Create app**, choose your repository, branch, and `app.py` as the main file.
4. Select **Deploy**. Wait for the build to finish.
5. Copy the public `streamlit.app` URL and share it.

## Scientific scope
The 30 entries are representative protein sequences/segments for an educational demonstration.
For selected large proteins, the sequence is a representative segment rather than a verified full-length canonical sequence.
Reference DNA is generated by deterministic reverse translation, so it is a valid coding demonstration but not the native gene sequence.
The classifier is trained and benchmarked on the same small reference dataset; its training accuracy is not a measure of generalization.
